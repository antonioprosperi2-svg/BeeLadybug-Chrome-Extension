# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

1.0.5 is the version in `manifest.json`. Older 1.0.x releases get security fixes on this line. Versions before 1.0 are not supported.

## Reporting a vulnerability

Report a vulnerability privately with a GitHub Security Advisory:

https://github.com/antonioprosperi2-svg/BeeLadybug-Chrome-Extension/security/advisories/new

There is no email address for security reports. Please do not open a public GitHub issue for a vulnerability, and do not post exploit details in discussions.

Include the extension version, the file or check involved, and a short description of the impact. If you can, add steps that show the problem on a page you control.

You will get a reply through the advisory. Please allow a few days for a first response. A confirmed issue will be fixed in a 1.0.x release, and the advisory can be published after the fix is available.
